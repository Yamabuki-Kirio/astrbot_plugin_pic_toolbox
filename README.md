> [lirundong093-glitch/astrbot_plugin_pic_toolbox](https://github.com/lirundong093-glitch/astrbot_plugin_pic_toolbox)
> 二次开发，遵循 AGPL-3.0 许可证。这是根据个人实际使用需求维护的公开版本，
> 不代表上游官方版本，也不发布到 AstrBot 插件市场。

## 与上游版本的区别

本维护版在上游图片处理能力基础上进行了以下调整：

- 新增 `万花筒`、`像素化`、`浮雕`、`油画`、`故障风` 五种效果。
- 万花筒采用 meme-generator-rs 的同心圆错位布局，输出 1200×1200 图片。
- 支持 AstrBot 4.29.1 返回的本地绝对路径和 `file://` 图片地址。
- 修复引用 GIF 被当作 HTTP URL 下载而处理失败的问题。
- 支持引用 QQ 系统表情后执行图片效果（含新版动态表情，如 Face 480）。
- 提高本插件图片指令的处理优先级，命中后停止事件传播，避免其他图片插件重复回复。
- 增加静态图、GIF、本地路径和 `file://` 输入的自动化测试。
- 插件版本更新为 `v1.3.2`。

## 图片来源

插件可以处理普通图片、动态 GIF、QQ 系统表情和 QQ 用户头像。当一条指令中同时存在多种图片来源时，按以下顺序选择：

1. 被 `@` 用户的 QQ 头像（需开启 `enable_at_avatar`）。
2. 引用消息中的图片或 QQ 系统表情。
3. 当前消息直接携带的图片或 QQ 系统表情。

支持 HTTP(S)、AstrBot 本地绝对路径和 `file://` URI，单张输入上限为 100 MB。

## 使用示例

### 处理引用图片

1. 引用一张图片或 GIF。
2. 发送 `/万花筒`、`/左对称`、`/反色` 等指令。
3. 机器人返回处理后的图片或 GIF。

### 处理 QQ 系统表情

1. 发送一个 QQ 自带的系统表情。
2. 引用该表情并发送 `/左对称` 或其他图片指令。
3. 插件根据 `Face ID` 获取对应素材，新版表情会尽量保留 APNG 动画。

```text
用户：[QQ 表情]
用户：[引用上述表情] /左对称
机器人：[处理后的动图]
```

### 处理用户头像

```text
/万花筒 @用户
/摸头 @用户
/左对称 @用户
```

## QQ 表情支持范围

| 表情类型 | 支持状态 | 说明 |
| --- | --- | --- |
| QQ 系统表情 `Face` | 支持 | 包括新版 4xx 编号表情，例如 Face 480 |
| 旧版 QQ 系统表情 | 支持 | 新素材获取失败时会尝试腾讯旧素材地址 |
| 商城/超级表情 `mface` | 暂不支持 | AstrBot 4.29.1 aiocqhttp 适配层会忽略该消息段 |
| 自定义收藏表情 | 视上报类型而定 | 若平台按普通 `Image` 上报即可处理 |

QQNT 新表情素材运行时优先从 [QFace](https://github.com/koishijs/QFace) 公开索引读取，因此 AstrBot 所在环境需要能够访问对应网络资源。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `enable_at_avatar` | `true` | 允许获取被 `@` 用户的头像 |
| `match_mode` | `false` | 开启后可以省略指令前的 `/` |
| `gif_speed_allow_frame_drop` | `false` | GIF 超过 50 FPS 时是否允许丢帧 |

## 安装

可以使用以下任一方式：

1. 下载仓库 ZIP，通过 AstrBot 管理面板上传安装。
2. 将解压后的 `astrbot_plugin_pic_toolbox` 目录放入 `AstrBot/data/plugins/`。
3. 从旧版升级时，覆盖插件目录后在管理面板重载插件，必要时重启 AstrBot。

依赖：

```text
Pillow>=10.0.0
requests>=2.25.0
numpy>=1.24.0
opencv-python-headless>=4.8.0
```

## 常见问题

### 引用 QQ 表情后没有反应

- 确认引用的是 QQ 系统表情，而不是商城 `mface` 表情。
- 确认指令带有 `/`；只有开启 `match_mode` 后才能省略。
- 查看 AstrBot 日志中是否出现素材下载失败，并检查容器的外网访问。

### 同一指令返回两张图

通常是其他图片或表情包插件也命中了同一关键词。本维护版已在命中后停止事件传播；如仍重复，请检查其他插件的监听优先级和自动补图功能。

### 引用 GIF 时提示 URL 无协议

请确认已更新到 `v1.3.2` 或更高版本。本维护版已支持 AstrBot 返回的本地绝对路径和 `file://` URI。
